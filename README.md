# FORMA ARCHITECTS

Концептуальный сайт архитектурной студии для портфолио AI-студии NOVARY. HTML5, CSS3, Vanilla JavaScript. Без сборки, npm и сторонних библиотек.

## Опубликованный сайт

**[https://egprefanov7117.github.io/forma-architects/](https://egprefanov7117.github.io/forma-architects/)** — GitHub Pages.

Сайт размещён в подкаталоге `/forma-architects/`. Пути к CSS, JavaScript, шрифту и фотографиям относительные; возврат со страницы источников ведёт в корень проекта. Canonical и Open Graph URL на обеих страницах абсолютные. Для Open Graph и Twitter Card используется `assets/images/social-preview.jpg` (JPEG, 1200 × 630); вымышленные аккаунты соцсетей в метаданных не указываются.

## Локальный запуск

Из Терминала:

```sh
cd forma-architects
python3 -m http.server 4174 --bind 127.0.0.1
```

Откройте **http://127.0.0.1:4174**. Остановка: `Ctrl+C`. Также можно открыть `index.html` напрямую: все ресурсы локальные, JavaScript не использует fetch или модули.

Для проверки такой же структуры URL, как на GitHub Pages, запустите сервер из родительского каталога:

```sh
python3 -m http.server 4174 --bind 127.0.0.1 --directory ..
```

Тогда адрес проекта — **http://127.0.0.1:4174/forma-architects/**. Canonical остаётся публичным адресом даже при локальном просмотре.

## Файлы

- `index.html` — главная страница, семантические разделы и диалоги.
- `styles.css` — типографика, адаптивная сетка, состояния элементов, анимации.
- `script.js` — мобильная навигация, диалоги проектов, демонстрационные контакты, появление элементов.
- `credits.html` — доступная с сайта страница авторов фотографий.
- `CREDITS.md` — источники и лицензии материалов.
- `QA_REPORT.md` — результаты проверок и ограничения.
- `assets/favicon.svg` — знак FORMA.
- `assets/fonts/manrope.woff`, `manrope.ttf`, `OFL-Manrope.txt` — локальный вариативный шрифт (WOFF для сайта, TTF-исходник) и лицензия.
- `assets/images/` — пять фотографий в трёх размерах WebP (15 файлов) и `social-preview.jpg` для превью ссылок.

## Возможности

- Минималистичная шапка, выразительный первый экран и раздел о философии.
- Асимметричное портфолио четырёх концептуальных проектов с подробностями в диалогах.
- Нативные раскрывающиеся услуги, четыре этапа работы и финальный контактный блок.
- Адаптивное мобильное меню: Escape, удержание клавиатурного фокуса и закрытие после выбора раздела.
- Плавная якорная навигация; перенос фокуса к целевому разделу; ссылка пропуска навигации.
- Диалоги с нативной блокировкой фона, Escape и возвратом фокуса.
- Сдержанное появление разделов и hover-эффекты с учётом `prefers-reduced-motion`.
- Responsive images, зарезервированные пропорции, приоритетное hero-изображение, lazy loading ниже первого экрана.
- SEO, Open Graph, русская локаль, доступные названия кнопок и видимые focus-состояния.
- Все медиа и шрифт локальные; нет аналитики, cookie, запросов к API и внешних runtime-зависимостей.

Контакты и соцсети явно демонстрационные: нажатие открывает пояснение. Отправки заявок и серверных форм нет. Все изображения — референсы, а проекты и студия вымышлены.
